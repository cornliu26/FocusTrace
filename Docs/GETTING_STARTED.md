# FocusTrace 新手教学

这份指南只回答一件事：第一次打开后，怎样真正得到一条可回顾的工作轨迹。

你不需要先设置训练、允许应用或 Codex。先完成下面四步即可。

## 1. 创建当前工作流

第一次启动只填写一个内容：**你现在准备持续推进什么**。

可以写：

- 排查登录问题
- 完成性能复盘
- 准备周会材料

工作流保存的是持续工作的上下文，不是一条临时待办。期望产出和允许应用可以以后再补。

## 2. 在真正工作的桌面绑定

创建完成后：

1. 切回真正工作的普通桌面或全屏窗口；
2. 点击屏幕顶部状态栏里的 FocusTrace 图标；
3. 点击“选择并绑定当前桌面”，选择刚创建的工作流。

绑定必须从状态栏完成。FocusTrace 主窗口可能位于另一个 macOS 桌面，在主窗口内绑定反而会绑定错地方。

同一个工作流可以绑定多个桌面。例如，代码桌面和同一项目的全屏浏览器都可以属于“排查登录问题”。

## 3. 正常工作

绑定完成后可以关掉主窗口。只要处于设置的工作时段，FocusTrace 就会在本机记录前台应用和工作流区间。

不需要一直盯着时间轴，也不需要为合理的工具切换手动打标签：

- 在同一工作流里切换终端、Codex、浏览器，仍然属于同一上下文；
- 桌面变化不自动等于分心；
- 前三个有效工作日是基线期，只记录，不发送分心提醒。

状态栏会显示当前工作流。主窗口左下角显示“工作时段记录中”时，说明自动采集已经生效。

## 4. 下班后再回顾

工作结束后打开：

- **时间轴**：先看工作流，再看主应用，最后看高切换区间；
- **回顾分析**：看最近工作日的趋势，只选择一项可以验证的调整；
- **专注训练**：想刻意训练时再使用，不是日常记录的前置条件。

数据不足或归因不可靠时，FocusTrace 会明确说“当前不能据此判断注意力”，不会用一次切屏制造结论。

## 遇到打断时

### 突然收到一个需求

从状态栏点击“收下一个需求”。它只进入需求箱，不会切换或绑定当前工作流。准备真正处理时，再点击“处理”。

### Agent、构建或测试还在等待

离开当前工作流前，点击“保存返回点”，只写回来后立刻做的第一步，例如“看测试结果并修复第一个失败”。切回对应桌面时，这一步会重新出现。

## 没有看到数据怎么办

按下面顺序检查：

1. 状态栏是否显示了正确的工作流；
2. 是否处于设置的工作日和工作时间；
3. “暂停应用切换记录”是否关闭；
4. 是否刚完成首次设置——前三个工作日没有提醒是正常的，但时间轴仍应更新。

如果时间轴应用片段在更新、工作流轨迹却为空，回到工作桌面，从状态栏重新绑定一次。

## 以后再开的能力

- **允许应用**：开始专注训练前再设置；
- **需求箱**：口头需求较多时使用；
- **Codex 每日行动复盘**：需要自动生成“当前问题、今天怎么做、如何验收”时再接入；
- **阶段 2**：至少积累 10 个工作日和 20 次训练后才会启用。

FocusTrace 只记录前台应用、时间、工作流标签和训练反馈，不读取窗口标题、网页地址、聊天对象、输入内容或手机行为。它是工作习惯工具，不提供 ADHD 诊断或治疗。
