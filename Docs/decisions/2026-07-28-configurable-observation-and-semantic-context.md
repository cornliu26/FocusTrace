# 决策：让每日回顾配置分析重点，而不动态扩大原始采集

- 状态：实施
- 日期：2026-07-28
- 负责人：FocusTrace
- 主要产品支柱：改善

## 问题

FocusTrace 当前固定展示相同的一组指标，不能说明“今天为什么重点分析这个问题”，Codex 也只把工作流与需求标题当作命名标签，没有明确判断两次工作是否共享目标与交付物。若直接把“动态采集”实现为改变原始事件的抽样率，会破坏时间轴完整性并让跨日比较产生偏差；若仅凭标题相似度判断切换成本，又会把相似工具、相似措辞与真实上下文连续性混为一谈。

## 预期结果与证据

每日回顾生成一个版本化观察配置：初始为四类证据均衡分配；有当天与近 7 个可比工作日后，根据数据质量、应用碎片、上下文恢复和工作流语义证据调整分析配额。用户展开“今天重点观察什么”时能看到比例、配置来源和理由。

Codex 在审计一条工作流路线前，必须结合工作流标题、关联需求标题、切换原因、目的地停留、30 分钟内返回和恢复点，把上下文关系标为“同一交付物 / 相邻交付物 / 不同目标 / 无法判断”。文字相似只能形成假设，不能独立触发提醒或分心结论。

Codex 写回协议升级为 v3，并携带不展示的 `analysisAudit`。若选择工作流路线作为当天主要问题，必须精确引用聚合报告中同一“起点—终点—理由”至少两次，且数据来源必须包含原生语义事件；App 和安装器都会拒绝不存在、只有一次或仅由旧时间轴推断的路线。聚合报告同时显式写入用户所选的 `reportCivilDate`，避免本地零点编码成 UTC 前一天后，分析被安装到错误日期。旧 v1/v2 写回继续可读，但新分析不能再只靠流畅文字通过校验。

本地每日建议同样不能只看工作流切换次数。只有至少两次原生最终跳转被用户说明为“等待结果”或“被迫中断”，并且当天没有保存返回点时，才建议练习一次返回点闭环；验证只检查是否真的保存并返回，不以切换次数下降冒充改善。

可观察证据是：

- 无可用数据时使用明确的初始均衡配置；
- 数据质量不可靠时，分析重点转向修复数据而非判断注意力；
- 高频工作流切换或恢复失败时，对应证据类别获得更高分析配额；
- 所有配额之和始终为 100%，报告写明来源和规则版本；
- 原始时间轴仍完整记录相同的最小事件集合；
- Codex 指令明确禁止仅凭标题相似度判断切换负担。
- Codex 路线结论必须能由写回校验器反向定位到至少两次原生聚合证据。

## 边界

- 本次明确不解决：临床诊断、从标题生成心理评分、云端语义向量、自动增频弹窗、自动修改训练计划。
- 新增数据及用途：在聚合日报中加入版本化观察配置、分析配额和固定干预策略来源；在 Codex 写回中加入隐藏的分析来源、所选路线和上下文关系，只用于验证结论来源与解释为什么关注某类证据。
- 明确不采集：新的屏幕内容、窗口标题、URL、输入内容、聊天对象、文件内容或自由文本切换理由。
- 必须由用户确认的决定：未来若改变弹窗门槛或训练计划，仍需用户确认；本次只自动调整分析配额。
- 数据不足、失败或权限缺失时的降级：回到均衡初始配置；数据质量不可靠时只给一项数据修复，不生成行为结论。

## 完整流程

1. 触发：用户打开某天每日回顾，或生成当天聚合报告。
2. 唯一主要行动：先阅读当天唯一建议；需要核对时展开“今天重点观察什么”。
3. 反馈：展开区显示四类分析配额、首要证据、配置来源、近 7 日样本数和固定采集边界。
4. 中断后的恢复：关闭展开区不改变任何设置；下次生成报告时按新聚合证据重新计算。
5. 完成或退出：用户无需保存配置；分析计划是可重建的报告产物。
6. 验证：检查配额、来源、跨日输入和 Codex 的单问题单行动写回是否一致。

## 研究依据与产品映射

这些依据来自认知心理学、组织行为与数字干预设计，不是 FocusTrace
治疗 ADHD 的临床试验证据。它们只用于约束交互假设：

- [Monsell 的任务切换综述](https://pubmed.ncbi.nlm.nih.gov/12639695/)显示，切换后的反应通常更慢、更易出错；准备可以降低但不能消除切换成本。产品因此不把“允许准备”宣传成消除成本，也不阻断所有切换。
- [Leroy 的注意残留实验](https://www.sciencedirect.com/science/article/abs/pii/S0749597809000399)显示，从未完成任务切走会损害后续任务表现；[Leroy 与 Glomb 的后续研究](https://pubsonline.informs.org/doi/10.1287/orsc.2017.1184)显示，简短的 ready-to-resume 计划可缓解这一影响。产品因此优先观察“未完成 + 无恢复点 + 很快返回”的路线。
- [Monk、Trafton 与 Boehm-Davis 的中断实验](https://doi.org/10.1037/1076-898X.14.4.299)显示，中断时长和认知要求会影响恢复耗时；[Altmann 与 Trafton 的研究](https://interruptions.net/literature/Altmann-CogSci04.pdf)进一步验证恢复延迟与线索作用。产品因此保留返回点与恢复结果，而不是采集更多内容。
- [任务规则差异实验](https://pmc.ncbi.nlm.nih.gov/articles/PMC11250929/)提示规则越不相似，实验任务中的切换成本可能越高；这不能直接外推为“工作流标题越像越轻松”。产品只将标题语义作为有界上下文假设。
- [JITAI 设计框架](https://pmc.ncbi.nlm.nih.gov/articles/PMC5364076/)要求明确决策点、裁剪变量、干预选项和规则，并把“不干预”作为一个选项以控制负担。产品因此把“分析配额”和“是否打断”分为两层，且允许“不提示”。
- [NICE 成人 ADHD 指南](https://www.nice.org.uk/guidance/ng87/chapter/recommendations)要求由受训专业人员进行完整临床与社会心理评估；本产品不把行为日志或本规则当作诊断、治疗或临床验证。

## 技术与回归

- 业务规则位置：`ObservationPlan.swift`、`WorkflowSwitchIntervention.swift`、`AutomationReport.swift`、`CodexWorkspaceContract.swift`。
- 新增单元测试：初始配置、数据质量聚焦、语义与恢复聚焦、配额归一化、报告兼容、标题语义边界，以及虚构或单次工作流路线不能进入回顾。
- 保护的既有回归测试：聚合隐私、单项建议、时间轴完整性、高频切换冷却、旧报告解码。
- 性能工作负载与预算：规则只读取已经计算的当日聚合和近 7 日趋势，不扫描新原始数据，不增加常驻轮询。
- 数据迁移与回退：日报协议新增可选字段并升至 v5；v4/v2 报告继续可解码。回退时忽略观察配置即可。

## 发布切片

首个切片只自动改变“分析注意力的分配”，不改变原始事件集合与弹窗门槛；在每日回顾折叠展示来源，并让 Codex 使用标题语义与行为后果联合审计。
