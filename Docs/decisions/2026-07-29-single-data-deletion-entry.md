# 决策：删除数据只保留一个可见入口

- 状态：已采用
- 日期：2026-07-29
- 负责人：FocusTrace
- 主要产品支柱：看清

## 问题

设置页把“删除当前日期”和“清空全部”同时展示成两个按钮，让低频且高风险的操作长期占据视觉注意力，也把“今天”误导成一种特殊的数据类型。

## 预期结果与证据

用户只看到一个“删除数据…”入口；进入后能明确选择删除当前查看日期或清空全部，并在执行前看到不可撤销提示。回归测试固定一个可见入口、两个删除范围和一次显式确认。

## 边界

- 本次明确不解决：数据恢复、日期范围批量删除和自动备份。
- 新增数据及用途：无。
- 明确不采集：无新增采集。
- 必须由用户确认的决定：按日删除或清空全部。
- 数据不足、失败或权限缺失时的降级：沿用现有错误提示，不执行部分删除。

## 完整流程

1. 触发：用户在“设置与数据”中进入“数据与保留”。
2. 唯一主要行动：点击“删除数据…”。
3. 反馈：系统展示两个明确范围和不可撤销说明。
4. 中断后的恢复：取消确认后不改变数据，可从同一入口重新进入。
5. 完成或退出：选择一个范围执行，或取消退出。
6. 验证：设置页只有一个删除入口；两个范围仍可达且都经过确认。

## 技术与回归

- 业务规则位置：`FocusTraceDataSettingsContract`。
- 新增单元测试：`settingsDataControlsUseOneDeletionEntryWithTwoConfirmedScopes`。
- 保护的既有回归测试：数据与保留三行顺序、危险色和删除实现保持不变。
- 性能工作负载与预算：不改变。
- 数据迁移与回退：无数据迁移；可独立回退设置页入口。

## 发布切片

仅合并两个可见按钮为一个入口，并复用现有按日删除和全部删除实现。
