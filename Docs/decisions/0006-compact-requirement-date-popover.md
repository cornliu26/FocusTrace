# 决策：让需求截止日期使用紧凑且一致的图形日历弹层

- 状态：已采纳
- 日期：2026-07-27
- 负责人：FocusTrace
- 主要产品支柱：不丢

## 问题

需求整理页把 macOS 系统图形日历直接嵌入表单。它占据整块卡片的视觉中心，系统蓝色焦点描边又与 FocusTrace 的圆角、颜色和按钮体系不一致。用户只是确认一个日期，却需要先穿过一大块高权重控件，时间、重要程度和工作流三个独立决定因此失去层级。

## 预期结果与证据

截止日期卡片只显示一个紧凑的日期入口。点击后在入口附近弹出与时间轴相同的 FocusTrace 图形日历；再次点击关闭，选中日期后自动收起。日历允许选择今天及未来日期；编辑已有逾期需求时仍允许保留或重新选择原有日期。

验收证据：

- 表单正文不再内嵌系统 `DatePicker` 图形日历；
- 日期入口与外部 FocusTrace 日期控件使用同一圆角、边框、颜色和弹层；
- 第一次点击打开、第二次点击关闭，选择日期后收起；
- 需求截止日期仍是图形日历，不退化成列表或文本输入；
- 日期范围规则允许未来日期，不允许无意选择早于可用下界的日期。

## 边界

- 本次明确不解决：时间点、时区选择、重复截止日期、日历同步、自然语言日期解析和排程。
- 新增数据及用途：不新增字段，只读写现有 `dueDate`。
- 明确不采集：不读取系统日历、会议、提醒事项或任何外部内容。
- 必须由用户确认的决定：是否有截止日期以及具体日期。
- 数据不足、失败或权限缺失时的降级：弹层关闭时保留当前选择；已有截止日期不会因视觉升级被改写。

## 完整流程

1. 触发：用户在需求详情中开启“有明确截止日期”。
2. 唯一主要行动：点击紧凑日期入口。
3. 反馈：入口附近显示 FocusTrace 图形日历，并突出当前选择。
4. 中断后的恢复：点击入口、弹层外部或 Escape 关闭，当前日期保持不变。
5. 完成或退出：选择日期后弹层自动收起；保存安排后写入现有截止日期字段。
6. 验证：重新打开需求详情时显示保存的日期，布局不再被日历撑高。

## 技术与回归

- 业务规则位置：`FocusTraceCore/UXStabilityContract.swift` 的日期范围与弹层契约。
- 新增单元测试：需求日期弹层契约、未来日期可选、下界限制和弹层两次点击开关。
- 保护的既有回归测试：图形日历形式、日期标准化、图形日历性能缓存、时间轴日期弹层和日期列表禁用。
- 性能工作负载与预算：继续复用月份布局缓存和相邻月份预热；不新增每秒刷新。
- 数据迁移与回退：无数据迁移；回退 UI 不影响已保存的 `dueDate`。

## 发布切片

本次只替换需求截止日期的呈现和交互，不改变需求排序、提醒、重要程度或工作流归属。
